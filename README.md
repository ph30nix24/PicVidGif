# 📸 PicVidGif

PicVidGif is a modern full-stack media browsing platform where users can discover, search, preview, download, and organize Images, Videos, and GIFs into personal collections. The platform offers a fast, responsive interface with secure authentication and an intuitive user experience.

---

## ✨ Features

### 🔐 Authentication
- User Registration & Login
- Secure JWT Authentication
- Protected Routes
- Logout with Token Blacklisting

### 🔍 Explore Media
- Browse High-Quality Images
- Browse Videos
- Browse GIFs
- Search Media by Keywords
- View Media Details
- Responsive Gallery Layout

### 📥 Download Media
- Download Images
- Download Videos
- Download GIFs

### ❤️ Collections
- Create Personal Collections
- Save Favorite Media
- Remove Media from Collections
- Organize Saved Content
- View Collection History

### 🎨 User Experience
- Fast and Responsive UI
- Modern Minimal Design
- Smooth Animations with GSAP
- Toast Notifications
- Redux Toolkit State Management

### ⚙ Backend
- RESTful API
- MongoDB Database
- Express.js Server
- JWT Authentication
- Firebase Integration
- Centralized Error Handling
